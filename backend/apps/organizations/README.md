# Organizations

این ماژول سازمان، تنظیمات عمومی و گزینه‌ها، عضویت و مجوزهای سازمانی، معاونت و پروژه را در SQLite مدیریت می‌کند. slug سازمان و slug پروژه در همان سازمان یکتا هستند و endpointهای مسیر خوانا فقط پس از بررسی عضویت داده می‌دهند. سازمان یک owner یکتا، admin با مجوز محدود مدیریت دسترسی و اعضای custom با مجموعهٔ مجوزهای پایدار دارد. انتقال مالکیت در یک transaction انجام می‌شود؛ API هیچ‌گاه سازمان را بدون owner نمی‌گذارد. نام، توضیحات، تصویر محدودشده و slug در دیتابیس ذخیره می‌شوند. مجوزهای ساخت/ویرایش hierarchy و مدیریت اعضا سمت سرور بررسی می‌شوند. دعوت در نسخهٔ فعلی به حسابی که از قبل در سامانه وجود دارد وصل می‌شود.

وابستگی‌ها: جداول `users`, `organizations`, `organization_members`, `divisions`, `projects` و migrationهای `008_organizations_and_divisions.sql`, `010_organization_settings_and_members.sql`. مسیرهای HTTP در `server.js` آن را مصرف می‌کنند. فرانت‌اند `lib/api/organizations.ts`, `projects.ts` و درخت `features/projects/organization-project-tree.tsx` از این API استفاده می‌کنند.
