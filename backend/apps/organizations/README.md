# Organizations

این ماژول سازمان، تنظیمات عمومی و گزینه‌ها، عضویت و مجوزهای سازمانی، معاونت، پروژه و فید فعالیت سازمان را در SQLite مدیریت می‌کند. slug سازمان و slug پروژه در همان سازمان یکتا هستند و endpointهای مسیر خوانا فقط پس از بررسی عضویت داده می‌دهند. سازمان یک owner یکتا، admin با مجوز محدود مدیریت دسترسی و اعضای custom با مجموعهٔ مجوزهای پایدار دارد. انتقال مالکیت در یک transaction انجام می‌شود؛ API هیچ‌گاه سازمان را بدون owner نمی‌گذارد. نام، توضیحات، تصویر محدودشده و slug در دیتابیس ذخیره می‌شوند. `organization-activity-repository.js` رخداد ساخت تسک، تغییر وضعیت و کامنت را ثبت می‌کند؛ صفحه‌بندی از cursor پایدار SQLite استفاده می‌کند و endpoint فعالیت فقط به اعضای سازمان پاسخ می‌دهد. مجوزهای ساخت/ویرایش hierarchy و مدیریت اعضا سمت سرور بررسی می‌شوند. دعوت در نسخهٔ فعلی به حسابی که از قبل در سامانه وجود دارد وصل می‌شود.

`PATCH /projects/:projectId/settings` نام و توضیحات پروژه را با مجوز `editProject` ذخیره می‌کند؛ slug پروژه هنگام ویرایش ثابت می‌ماند.

وابستگی‌ها: جداول `users`, `organizations`, `organization_members`, `organization_activity`, `divisions`, `projects` و migrationهای `008_organizations_and_divisions.sql`, `010_organization_settings_and_members.sql`, `011_organization_activity.sql`. مسیرهای HTTP در `server.js` آن را مصرف می‌کنند. فرانت‌اند `lib/api/organizations.ts`, `projects.ts` و `features/organizations/organization-activity-feed.tsx` و درخت `features/projects/organization-project-tree.tsx` از این API استفاده می‌کنند.
