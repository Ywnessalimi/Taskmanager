# Auth

این ماژول حساب اولیه، ورود با ایمیل و رمز، نشست‌های پایدار، ویرایش پروفایل، فهرست/لغو نشست‌ها و خروج را برای API نگه‌داری می‌کند. رمزها با `scrypt` هش می‌شوند و مقدار cookie خام فقط به مرورگر داده می‌شود؛ SQLite فقط hash نشست را ذخیره می‌کند. تابع `hashPassword` همین قالب هش را برای ساخت حساب‌های نمونهٔ صریح نیز فراهم می‌کند. شناسهٔ عمومی، User-Agent مرورگر و آخرین فعالیت نشست نیز ذخیره می‌شوند؛ API فقط نشست‌های کاربر جاری را مدیریت می‌کند. `PATCH /api/v1/auth/me` نام، ایمیل، توضیحات و آواتار تصویری محدودشده را ذخیره می‌کند.

وابستگی‌ها: `database.js`، migration `007_users_and_sessions.sql` و متغیرهای محیطی `INITIAL_ADMIN_EMAIL`, `INITIAL_ADMIN_NAME`, `INITIAL_ADMIN_PASSWORD`, `SESSION_COOKIE_SECURE`. مصرف‌کننده‌ها: مسیرهای `/api/v1/auth/*` در `server.js` و لایهٔ ورود فرانت‌اند. تنها وقتی جدول کاربران خالی است، تنظیمات اولیه یک حساب می‌سازند؛ هیچ دادهٔ دمو به‌صورت خودکار ایجاد نمی‌شود.
