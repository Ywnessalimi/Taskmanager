# notifications

این اپ اعلان‌های تخصیص تسک و ارجاع تیکت را در SQLite ثبت و برای گیرنده می‌خواند؛ وضعیت خوانده‌شدن نیز در همین منبع پایدار ذخیره می‌شود. مقصد ارجاع تیکت، شناسه و عنوان Ticket و در صورت وجود شناسهٔ پروژه را نگه می‌دارد.

وابستگی‌ها: `database.js` و migrationهای `006_notifications.sql` و `009_ticket_assignment_notifications.sql`؛ مسیرهای HTTP در `server.js` این repository را مصرف می‌کنند. گیرنده از شناسهٔ کاربر واقعی گرفته می‌شود و نام/هویت عامل از نشست معتبر سرور می‌آید.

مصرف‌کننده: `frontend/src/lib/api/notifications.ts` برای صفحهٔ اعلان‌ها و پیش‌نمایش هدر. رویداد تخصیص Task و ارجاع Ticket اعلان می‌سازند و مقصد هر اعلان جزئیات همان موجودیت است.

migration 013 شناسهٔ recipient_id را اضافه می‌کند. گیرندگان هم‌نام مستقل‌اند؛ fallback نام فقط برای دادهٔ قدیمی با نام یکتای سراسری مجاز است. دستیار پیش از خلاصه‌سازی دسترسی مقصد را بررسی می‌کند.

گیرندهٔ تخصیص Task باید عضو پروژه باشد. فهرست اعلان HTTP نیز اعلان پروژه‌ای را فقط وقتی نشان می‌دهد که گیرنده همچنان به همان پروژه دسترسی دارد؛ این کنترل به `project_members` در migration 015 وابسته است.
