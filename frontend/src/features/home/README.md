# features/home

پیاده‌سازی صفحه‌ی «خانه» (تب اول). لیست سازمان‌ها به‌صورت آکاردئون که با باز شدن، پروژه‌های همان سازمان را زیرش نشان می‌دهد.

## چه‌کار می‌کند

- `workspace-list.tsx` → کامپوننت `WorkspaceList` (Client): هر سازمان یک ردیف است با نام (لینک به صفحه‌ی سازمان) + یک شورون باز/بسته (سمت چپ) که پروژه‌های آن سازمان را زیرش (تورفته) نشان/پنهان می‌کند. وقتی باز است، یک آیکون + هم کنار شورون ظاهر می‌شود که امکان افزودن پروژه‌ی جدید (فقط محلی/غیرماندگار فعلاً، بدون اتصال به بک‌اند) به همان سازمان را می‌دهد. **بدون آیکون نوع (building/briefcase) — طبق بازخورد کاربر حذف شد.**

## وابستگی‌ها

- داده: `src/lib/api/organizations.ts` (`getOrganizations`) و تایپ `Organization` در `src/lib/api/types.ts`.
- آیکون: `RemixIcon` (`arrow-up-s-line` / `arrow-down-s-line` برای شورون، `add-line` برای افزودن پروژه).
- مصرف‌کننده: `src/app/(tabs)/home/page.tsx`.

## ارتباط با بقیه‌ی بخش‌ها

نام سازمان به `/home/organizations/[id]` لینک می‌شود ([../organizations](../organizations))، نام هر پروژه به `/home/projects/[id]` ([../projects](../projects)). داده‌ی این سه صفحه از یک منبع مشترک (`src/lib/api/mock-data.ts`) می‌آید تا شناسه‌ها همیشه هماهنگ بمانند.

## نکات ناقص فعلی

افزودن پروژه از داخل آکاردئون فقط در state محلی مرورگر ذخیره می‌شود (با رفرش صفحه از بین می‌رود) — چون هنوز API/بک‌اند واقعی برای ساخت پروژه وجود ندارد.
