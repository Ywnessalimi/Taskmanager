# organizations

این فیچر ساختار سازمان، معاونت و پروژه را از API نمایش می‌دهد. صفحهٔ `/o/[organizationSlug]` از قاب workspace ساخت تسک استفاده می‌کند: سربرگ زمینه، جزئیات سازمان و فهرست معاونت/پروژه در پنل اصلی، فید فعالیت تمام‌قد در سمت چپ، کادر کامنت چسبیده به پایین و تب جزئیات/فعالیت در موبایل. `organization-activity-feed.tsx` اولین ۱۵ رخداد را می‌گیرد و صفحه‌های قبلی را با پیمایش به پایین بارگذاری می‌کند؛ رخداد ساخت تسک، تغییر وضعیت و کامنت از SQLite می‌آیند. `MembersDialog` کنار آواتارها دکمهٔ افزودن عضو دارد؛ پنجره، دعوت حساب موجود با ایمیل و انتخاب نقش هر عضو را با API سازمان انجام می‌دهد. افزودن پروژه نیز به API متصل است. صفحهٔ `/home/organizations/[id]/settings` نام، تصویر، توضیحات و slug سازمان را در API ذخیره می‌کند و اعضا را با نقش مالک، مدیر دسترسی و دسترسی سفارشی مدیریت می‌کند. انتخاب دسترسی سفارشی به صفحهٔ مجوزها می‌رود؛ بک‌اند یکتایی مالک و مجوز هر عملیات را کنترل می‌کند. تنظیمات گزینه‌ها نیز در SQLite نگه‌داری می‌شوند. مسیر `/o/[organizationSlug]/[projectSlug]` پروژه را از slug پایدار باز می‌کند؛ مسیرهای شناسه‌محور قدیمی به این مسیرها هدایت می‌شوند. درخت سازمان می‌تواند تصویر بارگذاری‌شده را طبق گزینهٔ نمایش در نوار کناری نشان دهد.

ساخت سازمان از فرم `OrganizationProjectTree` با دکمهٔ «ثبت» انجام می‌شود. پس از ساخت، تنظیمات سازمان با مکث کوتاه و بدون دکمهٔ ذخیره، از طریق `updateOrganizationSettings` در API ذخیره می‌شوند.

وابستگی‌ها: APIهای `src/lib/api/organizations.ts` و `src/lib/api/projects.ts`، helper مسیرهای `src/lib/organization-paths.ts`، قراردادهای `Organization`, `OrganizationMember` و `ProjectRef` در `src/lib/api/types.ts` و اجزای مشترک layout, tabs, avatar و dialog.

مصرف‌کننده‌ها: `app/(tabs)/projects`، `app/(tabs)/home/organizations/[id]`، `app/(tabs)/home/organizations/[id]/settings`، `app/(tabs)/home/organizations/[id]/settings/permissions/[memberId]`، مسیرهای عمومی‌نما در `app/(tabs)/o/` و صفحه‌های خانه و پروژه. دعوت به ایمیل کاربری که از قبل حساب دارد انجام می‌شود؛ سامانهٔ ثبت‌نام/دعوت عمومی هنوز فعال نیست.


در ناوبری نرم، Overview سازمان با WorkspaceRouteModal در slot موازی @modal باز می‌شود؛ پارامتر divisionId همان قاب را با معاونت انتخاب‌شده نمایش می‌دهد. بارگذاری مستقیم مسیر canonical از صفحهٔ مستقل استفاده می‌کند.
