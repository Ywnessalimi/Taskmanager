# projects

این فیچر درخت Organization → Division → Project، نمای کلی پروژه و نماهای Task (Tree، Board، Table، Timeline و Calendar) را ارائه می‌کند. در دسکتاپ، صفحهٔ فهرست سازمان‌ها و پروژه‌ها تمام عرض باقی‌مانده را پر می‌کند و زمینهٔ پیرامونی آن خاکستری بسیار روشن است. در List/Tree زیر هر ردیف دکمهٔ افزودن سریع تسک، ورودی عنوان متمرکز و ثبت با Enter دارد و Task تازه را در پروژه ذخیره می‌کند. گروه‌بندی Board بر اساس اولویت یا مسئول نیز ستون‌های افقی دارد؛ گروه اولویت با رنگ سطح اولویت مشخص می‌شود. در هدر جزئیات پروژه دکمهٔ بازگشت ندارد. صفحهٔ `/projects`، زیر هر سازمانِ باز دکمهٔ «معاونت جدید» و زیر هر معاونتِ باز دکمهٔ «پروژهٔ جدید» قرار دارد. `ProjectNavigator` عنوان سازمان را با فونت ۱۶px و فلش توپر نشان می‌دهد و ردیف معاونت ۸px فاصلهٔ سمت راست دارد. مدیر جاری می‌تواند با کشیدن دستگیره، پروژه را روی معاونت مقصد و معاونت را روی سازمان مقصد قرار دهد؛ دستگیره‌ها فقط برای سازمان‌های قابل‌مدیریت نمایش داده می‌شوند و API مبدأ و مقصد را کنترل می‌کند. سازمان، معاونت، پروژه و Task از API/SQLite می‌آیند؛ نمودارهای تاریخی و ترتیب/ستون سفارشی Board تاریخچهٔ پایدار ندارند.

وابستگی‌ها: `src/lib/api/organizations.ts`، `projects.ts` و `tasks.ts`؛ `TaskPanelProvider` برای ساخت/ویرایش Task؛ `@dnd-kit` برای Drag & Drop.

مصرف‌کننده‌ها: `/projects`، `/home/projects/[id]` و `/home/projects/MyTasks`. Board پروژه تیکت‌های دارای `projectId` همان پروژه را از API می‌خواند؛ Board «تسک‌های من» تیکت‌های بدون پروژه را نشان می‌دهد. پیوند Ticket به Task هنوز localStorage است و در سرور ذخیره نمی‌شود.
