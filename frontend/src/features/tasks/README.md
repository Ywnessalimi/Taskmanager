# tasks

فرم‌ها، جزئیات و نماهای ساخت/ویرایش Task را ارائه می‌کند. ساخت و ویرایش در API/SQLite ذخیره می‌شود؛ داده‌های ساختار پروژه و هویت از API می‌آیند. فایل پیوست Task، ذخیرهٔ نظر و عضویت چندکاربره هنوز پیاده‌سازی نشده‌اند.

وابستگی‌ها: `src/lib/api/tasks.ts` برای CRUD و گزینه‌های فرم، `src/lib/api/types.ts` برای Task و قراردادهای فرم، و اجزای مشترک تاریخ، تگ و پنل.

انتخابگر تکرار در `repeat-picker.tsx` از ورودی‌های فاصلهٔ زیرخط‌دار، کنترل شمار دفعات با دکمه‌های کاهش/افزایش، و پس‌زمینهٔ کم‌تیرگی استفاده می‌کند. تقویم مشترک `components/ui/date-picker-dialog.tsx` روز انتخاب‌شده را به شکل دایره‌ای نمایش می‌دهد.

مصرف‌کننده‌ها: صفحه‌های پروژه و «تسک‌های من»، اعلان‌ها، و مسیر `/tasks/new`. تغییرهای Board که از پنل جزئیات ذخیره شوند در SQLite می‌مانند؛ ترتیب و ستون‌های سفارشی Board فعلاً state محلی‌اند.
