# features/pages

صفحه‌های افزودنی سند و چت که از نوار تب پروژه و مسیر تجمیعی «تسک‌های من» باز می‌شوند.

## چه‌کار می‌کند

- `document-page.tsx` → `DocumentPage`: صفحه‌ی خالی برای نوشتن (عنوان، متن و شمارنده‌ی واژه).
- `chat-page.tsx` → `ChatPage`: فهرست پیام‌ها و ورودی ارسال با نام و آواتار کاربر جاری.

## وابستگی‌ها و مصرف‌کنندگان

- داده‌ی API ندارد؛ `ChatPage` نام کاربر جاری را از مصرف‌کننده به‌صورت prop می‌گیرد.
- `ProjectSectionTabs` در `features/projects` این صفحه‌ها را در پروژه و `/home/projects/MyTasks` نشان می‌دهد؛ `src/app/(tabs)/messages/page.tsx` هم از `ChatPage` برای مسیر `/messages` استفاده می‌کند.
- متن سند و پیام‌ها فقط در state مرورگرند؛ با رفرش پاک می‌شوند و چت بلادرنگ نیست.
