# features/pages

نوار تب اصلی صفحه‌ها و «صفحه‌های افزودنی» (سند و چت) که کاربر با دکمه‌ی + به آن اضافه می‌کند.

## چه‌کار می‌کند

- `section-tabs.tsx` → `SectionTabs` (Client): نوار تب اصلی با تب‌های ثابت «لیست» و «نمای‌کلی»، به‌علاوه‌ی هر صفحه‌ای که کاربر اضافه کرده.
  - ظاهر: پس‌زمینه‌ی روشن (`bg-background`)، یک بوردر کم‌رنگ زیر کل نوار، و تب فعال به رنگ برند (متن + خط زیرین). تنها استفاده‌ی رنگ برند در این نوار همان تب انتخاب‌شده است.
  - دکمه‌ی «+» انتهای نوار یک `DropdownMenu` باز می‌کند با دو گزینه: **سند** و **چت**. صفحه‌ی ساخته‌شده بلافاصله فعال می‌شود.
  - محتوای «لیست» و «نمای‌کلی» به‌صورت `ReactNode` از بیرون تزریق می‌شود، پس این کامپوننت چیزی درباره‌ی پروژه یا تسک‌های من نمی‌داند و هر دو صفحه می‌توانند از آن استفاده کنند.
- `document-page.tsx` → `DocumentPage`: صفحه‌ی خالی برای نوشتن (عنوان + متن + شمارنده‌ی کلمه). ویرایشگر متن غنی نیست.
- `chat-page.tsx` → `ChatPage`: فهرست پیام‌ها + ورودی ارسال. هر پیام با نام و اواتار کاربر فعلی ثبت می‌شود.

## وابستگی‌ها

- UI: `components/ui/{tabs, dropdown-menu, avatar, remix-icon}`.
- داده: هیچ ماژول API‌ای؛ فقط `currentUserName` را به‌عنوان prop می‌گیرد (صفحه‌ها آن را از `getCurrentUser()` می‌دهند).
- مصرف‌کننده‌ها: `src/app/(tabs)/home/projects/[id]/page.tsx` و `src/app/(tabs)/my-tasks/page.tsx`.

## نکات ناقص فعلی

- صفحه‌های افزوده‌شده، متن سند و پیام‌های چت **همه فقط در state مرورگرند**: با رفرش صفحه پاک می‌شوند، به کاربر دیگری نمی‌رسند و هیچ API‌ای پشتشان نیست. چت اتصال بلادرنگ (WebSocket) ندارد.
- صفحه‌ها قابل حذف یا تغییرنام نیستند و ترتیبشان ثابت است.
- چون این صفحه‌ها ذخیره نمی‌شوند، هنوز به مدل داده (`docs/BACKEND.md`) اضافه نشده‌اند؛ هر وقت ماندگار شدند باید موجودیت `Page` در سند بک‌اند تعریف شود.
