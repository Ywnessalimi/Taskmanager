# Assistant UI
پنل گفتگو از مینی‌بار دسکتاپ و موبایل باز می‌شود. ai-assistant-dialog.tsx پیام و شناسهٔ گزارش/پیش‌نمایش را در state نگه می‌دارد؛ Markdown بدون HTML خام نمایش داده می‌شود. چت جدید state گفت‌وگو و پیوست انتخاب‌شده را پاک می‌کند. کاربر یک فایل متنی، PDF، DOCX یا XLSX تا ۳ مگابایت و ۸۰۰۰ نویسه پیوست می‌کند؛ متن با API استخراج و همراه پیام برای مدل فرستاده می‌شود.
assistant-widgets.tsx پرسش چندگزینه‌ای، کارت‌های انتخابی ساخت/ویرایش با شرح و مسئول و زیرتسک، نتیجهٔ تأیید، نمودار/جدول و خروجی فایل را نمایش می‌دهد. تأیید فقط preview ID و selectedKeys می‌فرستد؛ اجرای ابزار و اعتبارسنجی در بک‌اند است.
assistant-connections.tsx در بخش Plug in حساب کاربری توکن MCP با پروژه‌ها و مجوزهای انتخابی ایجاد/لغو می‌کند؛ مقدار خام فقط هنگام صدور دیده می‌شود.
وابستگی‌ها: lib/api/assistant.ts، locale-provider، اجزای UI، API نشست‌دار assistant/integrations و دادهٔ پروژه. مصرف‌کنندگان: sidebar-nav و bottom-tab-bar. AI_GRADIENT برای سازگاری trigger قدیمی export می‌شود.
گردش قدیمی ai-workflow و ai-tools حذف شده است؛ هیچ اجرای تغییردهندهٔ مدل در مرورگر باقی نمانده. ساخت کارتابل موفق رویداد quire-dashboards-saved می‌فرستد تا انتخابگر دادهٔ سروری را تازه کند.
