# Assistant UI
پنل گفتگو از مینی‌بار دسکتاپ و موبایل باز می‌شود. ai-assistant-dialog.tsx پیام و شناسهٔ گزارش/پیش‌نمایش را در state نگه می‌دارد؛ Markdown بدون HTML خام نمایش داده می‌شود.
تاریخچهٔ حداکثر ۱۰ گفتگو در localStorage نگه‌داری می‌شود. دکمهٔ «چت جدید» فقط گفتگوی جاری را پاک می‌کند. تاریخچه در موبایل drawer، در پنل تمام‌صفحه sidebar و در پنل مودال یک ریل افقی ۷ تا ۱۰تایی است. `AIAssistantFab` دسکتاپ پنل تمام‌صفحه را باز می‌کند؛ `SidebarNav` و `BottomTabBar` پنل مودال را باز می‌کنند.
دکمهٔ «چت جدید» در هدر با واریانت outline و بوردر استاندارد نمایش داده می‌شود.
ورودی در دو بخش متن و نوار اکشن چپ‌به‌راست ثابت ساخته شده است: انتخاب فایل در سمت چپ، انتخاب حالت دسترسی در کنار آن و ارسال در سمت راست. فایل‌های XLSX، DOCX، CSV، TXT، Markdown و JSON به‌صورت موقت به درخواست دستیار پیوست می‌شوند. حالت «فقط خواندن» در درخواست به بک‌اند فرستاده می‌شود تا ابزارهای پیش‌نمایش تغییردهنده در سمت سرور مسدود شوند.
assistant-widgets.tsx پرسش چندگزینه‌ای، کارت‌های انتخابی ساخت/ویرایش با شرح و مسئول و زیرتسک، نتیجهٔ تأیید، نمودار/جدول و خروجی فایل را نمایش می‌دهد. تأیید فقط preview ID و selectedKeys می‌فرستد؛ اجرای ابزار و اعتبارسنجی در بک‌اند است.
assistant-connections.tsx توکن MCP با پروژه‌ها و مجوزهای انتخابی ایجاد/لغو می‌کند؛ مقدار خام فقط هنگام صدور دیده می‌شود.
وابستگی‌ها: lib/api/assistant.ts، locale-provider، اجزای UI، localStorage برای تاریخچهٔ محلی، API نشست‌دار assistant/integrations و دادهٔ پروژه. مصرف‌کنندگان: sidebar-nav، bottom-tab-bar و ai-assistant-fab. AI_GRADIENT برای سازگاری trigger قدیمی export می‌شود.
گردش قدیمی ai-workflow و ai-tools حذف شده است؛ هیچ اجرای تغییردهندهٔ مدل در مرورگر باقی نمانده. ساخت کارتابل موفق رویداد quire-dashboards-saved می‌فرستد تا انتخابگر دادهٔ سروری را تازه کند.
