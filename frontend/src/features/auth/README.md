# features/auth

این ماژول صفحهٔ ورود Quire را ارائه می‌کند. ورود با ایمیل و رمز به API واقعی متصل است، نشست سرور را در cookie امن دریافت می‌کند و خطاهای ورود را به کاربر نشان می‌دهد. ثبت‌نام عمومی غیرفعال است و مسیر `/signup` به `/login` برمی‌گردد.

وابستگی‌ها: `lib/api/auth.ts`, `lib/api/backend-client.ts` و قرارداد کاربر در `lib/api/types.ts`. API رمز را بررسی و نشست را در SQLite نگه می‌دارد؛ مرورگر cookie را با `HttpOnly` دریافت می‌کند. `src/proxy.ts` مسیرهای صفحه‌ای را برای نشست‌های موجود هدایت می‌کند و سرور API نشست را مرجع اعتبارسنجی می‌داند.

مصرف‌کننده‌ها: مسیر `/login`، `account-settings.tsx` برای خروج، و layoutهای محافظت‌شدهٔ اپ برای دریافت کاربر جاری. ظاهر صفحه از توکن‌های `.auth-theme` و `AuthHero` استفاده می‌کند. در دسکتاپ، زبان فارسی فرم را سمت راست و Hero را سمت چپ می‌گذارد؛ زبان انگلیسی ترتیب متناسب با LTR را حفظ می‌کند. Hero در اطراف محتوای برد فاصلهٔ عمودی دارد تا ستون‌ها به لبهٔ پایین قاب نچسبند. بازنشانی رمز در این نصب تک‌حسابی ارائه نمی‌شود.
