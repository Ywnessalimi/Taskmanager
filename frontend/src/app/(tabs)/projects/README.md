# projects route

ورودی محیط مستقل مدیریت پروژه است و همهٔ پروژه‌های کاربر را از همهٔ سازمان‌ها نشان می‌دهد. کارت هر پروژه به صفحهٔ همان پروژه در مسیر فعلی `/home/projects/[id]` می‌رود.

وابستگی‌ها: `lib/api/organizations.ts`، `features/projects/project-navigator.tsx` و دیکشنری زبان. مصرف‌کننده: لینک «پروژه‌ها» در مینی‌بار موبایل و دسکتاپ. صفحهٔ جزئیات پروژه همان `ProjectNavigator` را برای جابه‌جایی بین همهٔ پروژه‌ها استفاده می‌کند.
