# lib/api

لایهٔ دادهٔ فرانت با تایپ‌های مشترک در `types.ts` و داده‌های Mock در `mock-data.ts`. صفحه‌ها و فیچرها از توابع این پوشه برای خواندن داده استفاده می‌کنند؛ بک‌اند واقعی هنوز به آن وصل نشده است.

`tasks.ts` گزینه‌های پروژه/اعضا را از سازمان‌ها و پروژه‌های Mock می‌سازد. `createTask` و `updateTask` فقط ورودی را لاگ می‌کنند. ورودی ساخت اختیاریِ وضعیت، دنبال‌کنندگان، علاقه‌مندی، دقیقه‌های کارکرد و عنوان زیرتسک‌های اولیه توسط مودال جدید هدر استفاده می‌شود؛ فرم قدیمی همچنان فیلدهای پایه را می‌فرستد. این قرارداد ذخیرهٔ فایل یا نظر را شامل نمی‌شود.

مصرف‌کننده‌ها: layout سراسری برای گزینه‌ها، فیچرهای `tasks` و `projects` و صفحه‌های `app`. وابستگی‌های داده در هر فایل دامنه‌ای نگه داشته می‌شوند تا بعداً همان تابع با API جایگزین شود.

## تغییرات شرکت و تیکت

`Division` زیرمجموعهٔ شرکت است و `Project.divisionId/divisionName` مرجع معاونت‌اند. دادهٔ معاونت‌های Mock در `mock-data.ts` تعریف شده؛ `Organization.projects` نمای تجمیعی برای سازگاری است. `tickets.ts` قرارداد مستقل `createTicket(NewTicketInput)` را دارد که فقط ورودی را لاگ می‌کند؛ مصرف‌کننده فیچر tickets است.
