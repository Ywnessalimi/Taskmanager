# components/ui

اکثر فایل‌های این پوشه با `npx shadcn@latest add <name>` تولید شده‌اند — جدول کامل و دلیل نصب هرکدام در [docs/FRONTEND.md](../../../../docs/FRONTEND.md) بخش «وضعیت فعلی پیاده‌سازی» است، نه اینجا.

`dialog.tsx` واریانت `taskWorkspace` را برای `features/tasks/new-task-dialog.tsx` دارد: در موبایل تمام‌صفحه، از `sm` به بالا با فاصلهٔ فیزیکی ۱۶px از راست/بالا/پایین و عرض حداکثر ۱۰۷۲px. محتوا پدینگ و اسکرول جزئیات/فعالیت‌ها را مدیریت می‌کند؛ این واریانت از قاب AI مستقل است.

## استثنا: `date-picker-dialog.tsx`

تنها فایل این پوشه که **از shadcn نیست** — دست‌ساز است، چون shadcn یک کامپوننت date-picker آماده ندارد و پروژه هم کتابخانه‌ی تاریخ خارجی نصب نمی‌کند (رجوع به [docs/FRONTEND.md](../../../../docs/FRONTEND.md) بخش «تنها کتابخانه‌ی خارجی UI پروژه `@dnd-kit` است»).

- `DatePickerDialog({ value, onChange, trigger })`: مودال انتخاب تاریخ، خیلی مینیمال (فقط شبکه‌ی روزهای ماه + پیمایش ماه + دکمه‌ی «امروز»/«پاک کردن»). `trigger` باید از قبل با `<DialogTrigger>` (از `components/ui/dialog.tsx`) بسته شده باشد — این کامپوننت فقط `Dialog`/`DialogContent` را دورش می‌گذارد.
- **زبان تعیین می‌کند کدام تقویم نشان داده شود**، نه یک prop جدا: فارسی (`useLocale().locale === "fa"`) → تقویم جلالی از `src/lib/jalali.ts` (همان ماژولی که `TimelineView`/`CalendarView` استفاده می‌کنند — رجوع به هشدار «تقویم واقعی نیست» در همان فایل)؛ غیر آن (انگلیسی) → تقویم میلادی واقعی با `Date` بومی جاوااسکریپت (کبیسه/طول ماه دقیق، چون کتابخانه‌ی خارجی لازم ندارد).
- **هیچ تبدیل جلالی↔میلادی واقعی انجام نمی‌شود** — چون `jalali.ts` تقویم واقعی نیست (نمی‌شود آن را به میلادی واقعی تبدیل کرد) و مقدار انتخاب‌شده فعلاً جایی ذخیره نمی‌شود (`createTask` نو-آپ است). اگر روزی این فرم به بک‌اند واقعی وصل شد و لازم بود یک تسک با `dueDate` جلالی در نمای میلادی هم درست نشان داده شود، اول باید کل مسئله‌ی «تقویم جلالی این پروژه واقعی نیست» حل شود، نه فقط این کامپوننت.
- «امروز» در حالت جلالی از `MOCK_TODAY` (`src/lib/api/mock-data.ts`) می‌آید نه `new Date()` — همان دلیلی که `src/lib/api/calendar.ts` دارد. در حالت میلادی چون تقویم واقعی است، از `new Date()` واقعی سیستم استفاده می‌شود.
- مصرف‌کننده‌ی فعلی: فقط `features/tasks/task-create-form.tsx` (فیلد «تاریخ سررسید»).

## ساخت موبایل مطابق KalaMarket

DialogContent واریانت createMenu برای منوی شناور ساخت موبایل دارد (شفاف، بدون ring و با گزینه‌های جدا)؛ overlayClassName امکان زمینهٔ مشکی ۳۰٪ بدون blur را فقط در این منو می‌دهد. سایر دیالوگ‌ها زمینهٔ قبلی را حفظ می‌کنند.

تصاویر نمونهٔ پروفایل در public/avatars/u1.svg تا u6.svg با پرتره‌های برداری مینیمال و رنگ ملایم جایگزین شدند؛ تمام مصرف‌کنندگان AvatarImage همان آدرس‌ها را استفاده می‌کنند.
