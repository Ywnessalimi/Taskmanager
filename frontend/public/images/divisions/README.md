# Division thumbnails

این پوشه پنج تصویر مربعی فشرده برای نمایش حوزهٔ معاونت‌ها دارد: محصول، عملیات، توسعه، بازاریابی و تصویر عمومی. تصاویر WebP نیستند و به‌صورت JPEG کوچک نگه‌داری می‌شوند تا در ردیف‌های فشرده سریع بارگذاری شوند.

وابستگی: `src/features/projects/division-image.ts` نام فارسی یا انگلیسی معاونت را به یکی از این فایل‌ها نگاشت می‌کند.

مصرف‌کننده‌ها: `OrganizationProjectTree` و `ProjectNavigator`، فهرست معاونت‌های Overview سازمان، و `WorkspaceList` در خانه.
